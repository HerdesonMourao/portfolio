# Herdeson Mourão — Portfolio

Portfolio pessoal de Herdeson Mourão, Fullstack Developer & Tech Lead.
Construído com **Vue.js 3 + Vite**.

---

## 💻 Rodando localmente

```bash
# Instalar dependências
npm install

# Dev server com hot reload
npm run dev

# Build de produção
npm run build

# Preview do build
npm run preview
```
